## 프로젝트 추진 배경

Project Promotion Background

- 생산설비통합관제시스템구축을통한설비데이터모니터링및장애대응체계구축

- 1 설비이상여부를작업자가직접확인하는방식으로고장인지및초기대응이지연

- 2 설비가동·정지·비가동 데이터가통합수집되지않아전체설비현황파악이어려움

- 3 실시간알람및모니터링체계가부족하여설비고장발생시생산중단위험증가

- 4 설비알람·고장·가동 이력이체계적으로축적되지않아데이터기반의유지보수판단이어려움

- 기존에분산관리되던설비데이터를통합하여정보통합관리체계구축

목표

- 실시간모니터링시각화및알람시스템으로설비장애대응속도를높여생산안정성및품질극대화

- 데이터기반분석환경을조성하여운영효율개선및데이터기반의사결정지원

## 개발 공통 사항

Development Common List

## 1. 통합 DB 설계 및 구성

- 설비별 데이터를 통합 관리할 수 있는 데이터베이스 구조 설계 및 구축

- 수집데이터의이력저장및화면조회를고려한테이블구성

## 2. Spring Boot 기반 백엔드 서버 구축

- PLC·설비·센서데이터수집결과를 DB와연동하고, 화면에서필요한데이터를 조회할수있는 API 개발

- 설비상태, 알람, 이력, 통계데이터제공기능구현

## 3. Web SCADA 기반 관제 화면 구성

- 설비상태와주요운영지표를실시간으로확인할수있는대시보드화면개발

- 설비상태, 알람, 이력조회등설비운영중심의관제기능구성

## 1) 전체데이터조회조건

- 페이지로드시전체공장기준최신데이터자동 조회

- 공장, 설비유형, 상태필터로조건별조회

## 2) 설비상태요약, 현황지표

- 전체설비수, 가동설비, 정지설비, 알람설비수를 카드로표시

- 상태별색상(청색/녹색/황색/적색)을적용하여 직관적상태확인

## 3) 종합설비효율

- 선택기간기준설비의가용률, 성능률, 품질률을 기반으로종합설비효율(OEE)을시각화

## 4) 설비상세현황

- 설비명, 상태, 가동시간, 최근알람, 마지막점검일을 테이블로제공

- 5) 설비상태분포 정렬및필터기능을통해특정설비빠른조회지원

- 설비의종합적인상태를그래프로직관적으로표시
