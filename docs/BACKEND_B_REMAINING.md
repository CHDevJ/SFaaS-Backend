# 백엔드 B 미완료 목록 (2026-11-17)

아직 백엔드 B의 전체 기능이 완료된 상태가 아니다. 도메인 계산·판정 서비스와 그 단위테스트를 구현했으며, 실제 API 및 저장소·자동 처리 연결은 남아 있다.

## 판단 기준

- API 계약은 docs/openapi.yaml v5를 우선한다.
- 소유권은 Confluence [백엔드 기능 개발 분배](https://sfaas5-team.atlassian.net/wiki/spaces/SF5/pages/1507330)를 참고한다. 이 페이지는 v4 기준이므로 카카오를 v5 텔레그램으로 바꿔 적용하고, API 개수와 이전 수집 규격은 현재 계약으로 사용하지 않는다.
- 구현 상태는 현재 로컬 소스 기준이다. DB·프론트엔드가 준비되지 않아도 가능한 계산·판정 로직을 먼저 작성했다.
- 110개 테스트 통과는 계산 및 포트 기반 단위테스트와 기존 애플리케이션 컨텍스트 테스트의 결과다. 실제 API·MySQL·Redis·텔레그램·WebSocket의 종단간 동작 완료를 뜻하지 않는다.

## A 담당과의 연결 경계

분배표상 인증·사용자·기준정보·측정 수집·설비 통신·시스템 설정·감사·STOMP 연결 기반은 A 담당이다. 현재 추가된 해당 영역의 코드도 저장소 인터페이스 또는 검증·계산 단계이며 A와 합칠 때 중복 구현과 포트 계약을 확인해야 한다.

B는 A가 제공하는 사용자/직책, 설비/데이터 항목, 측정/생산 이벤트, 판정/계산 설정, 감사 포트와 연결해야 한다. 실제 프론트엔드 구현은 B 백엔드 개발 범위에 포함하지 않는다.

## 선행 확인

- DB 담당: OpenAPI와 ERD의 알람 조치·오경보 상세·부품 교체 문자열 길이 및 교체 사유 코드/자유 입력 차이를 확정한다.
- A와 공동: 위 조회·이벤트·설정 포트와 STOMP 발행 기반을 연결한다.
- 현장 입력: 실제 임계값, PLC 주소/배율, 단가, 운영 시간을 확정한다.

프론트엔드 완성을 기다릴 필요 없이, 저장소 계약과 테스트용 구현을 통해 Controller·응용 서비스·이벤트·스케줄러 연결을 추가 개발할 수 있다.
